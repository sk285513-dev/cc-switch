# LexMind-Omni 專案背景說明 (CONTEXT.md)

## 專案目標
自動化將台灣法律補習班課程影片轉換為：
- 精校繁體中文逐字稿（.md）
- 時間軸字幕（.srt / .vtt）
- 純文字稿（.txt）
- RAG 向量檢索索引（_index.json）

## 課程來源
- **J 碟**：主要教材儲存（土地登記、民法、刑法、行政法等）
- **H 碟**：附加教材（憲法霖洄、民法A115、身分法B115、行政法霖迴B115、家事事件法115）

## 科目優先序（國考核心）
| 優先 | 科目 | Score |
|---|---|---|
| 最高 | 憲法 | 10 |
| 高 | 民法（含身分法）| 20 |
| 高 | 刑法 | 25 |
| 高 | 行政法 | 30 |
| 中 | 程序法（民訴/刑訴/家事）| 40 |
| 中 | 土地法規 | 50 |
| 一般 | 商事法（公司/票據/證交/稅法）| 60 |

## 系統組件
- `run_workflow.py`：主控排程，N=3 並列處理
- `stt_runner.py`：Gemini 雲端轉寫
- `merge_transcript.py`：分片合併 + 精校
- `markdown_formatter.py`：多格式輸出
- `watchdog_monitor.py`：系統守護與品管

## 品質標準（AGENTS.md 定義）
- 法律術語正確率 ≥ 98%
- 完整過濾口語贅字
- MD/SRT/VTT/TXT/JSON 五檔完整落地
- J 碟原始目錄同步備份
