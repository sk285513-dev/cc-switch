```
flowchart TD
    U[使用者<br/>編輯 Obsidian 筆記] --> OA[Obsidian App]

    OA --> V[Obsidian Vault<br/>各資料夾]

    subgraph ConfigSupervisor[PowerShell Config Supervisor]
        CS1[讀取/建立 config.json]
        CS2[檢查欄位完整性<br/>vault_path / ragflow_base_url / api_key / dataset_map]
        CS3[如有缺值→向使用者詢問並寫回 config.json]
        CS4[驗證：路徑存在 / RAGFlow URL 可連線 / API key 有效]
    end

    subgraph SyncEngine[Python Sync Engine]
        SE1[讀取 config.json]
        SE2[讀取 sync_index.json]
        SE3[掃描 Vault 指定資料夾<br/>找出新增 / 修改檔]
        SE4[依路徑查 dataset_map<br/>決定目標 dataset]
        SE5[呼叫 RAGFlow HTTP API<br/>上傳檔案內容與 metadata]
        SE6[更新 sync_index.json]
        SE7[寫入同步 log（成功 / 失敗）]
    end

    ConfigSupervisor --> SyncEngine

    CS1 --> CS2 --> CS3 --> CS4 --> SyncStart[啟動同步器]

    SyncStart --> SE1 --> SE2 --> SE3 --> SE4 --> SE5 --> SE6 --> SE7

    V --> SE3

    subgraph RAGFlowSide[RAGFlow 端]
        RFIngest[Ingestion Pipeline<br/>Parsing / Cleansing / Chunking]
        RFDatasets[各 Dataset（research / code / legal / logs）]
        RFIndex[Embedding & Index 建立]
    end

    SE5 --> RFIngest --> RFDatasets --> RFIndex

    note right of SE5
      使用 RAGFlow HTTP API
      Authorization: Bearer API_KEY
      body: file content + metadata
    end
```
