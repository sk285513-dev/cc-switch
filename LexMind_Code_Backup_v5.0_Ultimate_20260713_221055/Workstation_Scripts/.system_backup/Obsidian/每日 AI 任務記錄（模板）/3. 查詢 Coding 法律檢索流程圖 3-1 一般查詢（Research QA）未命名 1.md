sequenceDiagram

## 3-2 Coding / Bugfix Flow
```
sequenceDiagram
    participant U as 使用者
    participant UI as Coding UI / Agent
    participant RF as RAGFlow Retrieval
    participant DSCode as code & troubleshooting datasets
    participant CoderA as DeepSeek-Coder
    participant CoderB as Qwen2.5-Coder
    participant Judge as Gemma2:9b (Judge)
    participant Exec as Execution Env (Python/PowerShell)
    participant OB as Obsidian Vault

    U->>UI: 提出 coding / bugfix 任務
    UI->>RF: 查詢歷史 code / 修復案例 / 筆記
    RF->>DSCode: hybrid search
    DSCode-->>RF: 返回 code snippets + bug cases
    RF-->>CoderA: 提供 context + 任務
    RF-->>CoderB: 提供 context + 任務
    CoderA-->>UI: Patch/方案 A
    CoderB-->>UI: Patch/方案 B

    UI->>Judge: 請 Judge 比較 A/B 或整合
    Judge-->>UI: 最佳方案 / 綜合方案

    UI->>Exec: 執行 patch / 腳本 / 測試命令
    Exec-->>UI: 測試結果 / log / 錯誤

    UI-->>U: 回報結果與改動摘要

    Note over U,OB: 若為成功修復案例，整理成「錯誤與修復紀錄」筆記\n放入 Obsidian，後續再由同步器導入 troubleshooting_cases dataset
```
## 3-3 法律檢索 Flow

sequenceDiagram
    participant U as 使用者
    participant UI as RAGFlow / Legal Agent UI
    participant RF as RAGFlow Retrieval
    participant DSLegal as legal_statutes / cases / notes
    participant LM as 本地 LLM (法律向提示的 Gemma2:9b)
    participant OB as Obsidian Vault

    U->>UI: 提出法律問題 / 案件爭點
    UI->>RF: 查詢請求（含關鍵字 / 法條 / 案號）
    RF->>DSLegal: hybrid search (高 keyword weight + rerank)
    DSLegal-->>RF: 返回法條 / 判決 / 案件筆記 chunks
    RF-->>LM: 提供 evidence + 問題
    LM-->>UI: 產出結構化分析\n(法條 / 裁判 / 爭點 / 初步見解)
    UI-->>U: 顯示結果

    Note over U,OB: 若分析有參考價值，整理成「案件筆記」\n存於 03_法律與案件/30_案件筆記\n日後由同步器導入 legal_case_notes dataset
```
